# WOODCRAFT — Carpentry Workshop

A React + Vite carpentry planning app.

## Features
- Material sheet estimator with waste allowance
- Carpentry estimate builder in Ghana cedis (GHS)
- Editable material list, labour and transport
- Downloadable estimate text file
- Cutting schedule with part dimensions and total panel area
- Pinterest design inspiration links
- Local-device workshop posts
- Responsive mobile layout

## Run locally
1. Install Node.js (18 or newer).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown by Vite.

## Build
Run `npm run build`. The production files are created in `dist/`.

## Notes
This is a portable source edition of the WOODCRAFT app. The community section in this export saves posts in the current browser/device only; it is not the same shared multi-user backend as a hosted deployment. Material and sheet calculations are estimates. Confirm site dimensions, cutting layouts, supplier prices, and material specifications before purchasing or quoting.
